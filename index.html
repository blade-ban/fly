처음 한 번만: 순위 서버 만드는 방법
  1. 구글 스프레드시트를 새로 만들고 확장 프로그램 → Apps Script를 엽니다.
  2. 있던 글을 지우고 Code.gs 내용을 붙여 넣은 뒤, 맨 위 PASSWORD를 선생님 비밀번호로 바꾸고 저장합니다.
  3. 배포 → 새 배포 → 웹 앱, 실행: 나, 액세스: 모든 사용자 → 배포 → 권한 허용.
  4. 나온 웹 앱 URL을 위 칸에 붙여 넣고 ‘연결 확인’을 누릅니다.
  5. 한 번 만든 주소는 다른 게임에도 계속 쓸 수 있어요.

↺전에 만든 게임 고치기

불러와서 고친 뒤 새 링크를 다시 보내면 됩니다. 같은 게임으로 이어지므로 순위 기록도 그대로 이어져요. ‘새 게임으로 만들기’는 순위 기록을 따로 시작합니다. 마지막 작업은 이 브라우저에 자동 저장돼요.
